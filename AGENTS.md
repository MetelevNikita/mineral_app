# Инструкции проекта

## Работа с кодом

- Перед изменением изучи связанные файлы и текущую логику.
- Вноси минимальные изменения, необходимые для задачи.
- Сохраняй существующий стиль, структуру и способ написания кода.
- Не рефактори код, который не относится к задаче.
- Не добавляй новые зависимости без необходимости.
- Сохраняй незавершённые изменения пользователя.

## Показ изменений

- Перед редактированием открой целевой файл в VS Code на нужном месте.
- Во время работы кратко сообщай, какой файл и какую часть меняешь.
- После изменения показывай компактный diff или перечисляй изменённые строки.
- Добавляй кликабельные ссылки на изменённые файлы с номерами строк.

## Проверка интерфейса

- Для визуальных изменений запускай приложение и открывай нужную страницу в браузере.
- Держи страницу браузера открытой и обновляй её после изменений.
- Проверяй мобильный размер экрана, если изменение связано с телефоном или PWA.
- Не открывай браузер, если изменение не влияет на интерфейс.

## Проверка кода

- Запускай минимальную проверку, которая относится к изменению.
- Перед завершением задачи запускай `npm run build`.
- Если обнаружены посторонние ошибки, сообщи о них, но не исправляй без запроса.

## Ограничения

- Не изменяй `.env` и секреты без прямого запроса.
- Не выполняй commit, push или deployment без прямого запроса.
- Не удаляй файлы без необходимости.
